SPLUNK ENTERPRISE · SOC LAB

Windows Logon Triage in Splunk

I built a seven-panel dashboard that takes an analyst from Windows authentication trends to the host, account, and logon type behind a failed event. It uses Splunk's historical BOTS v3 practice dataset.

Dataset events
2,083,056
Successful Windows logons
427
Failed Windows logons
3

How I triaged the events

I used SPL to distinguish Event ID 4624 from 4625, chart both outcomes by time, and surface failed events in a sortable table. The table lets an analyst compare timestamps, hosts, accounts, and logon types before checking the raw records.

What the evidence showed

All three failed events had no usable source address in the returned records. My next step would be to correlate the host and timestamp with other available telemetry before attributing the activity.
